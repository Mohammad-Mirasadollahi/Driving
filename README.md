## سوالات و جواب های آیین نامه رانندگی
 - سوالات دقیقا همین موارد هست و البته شاید هم ی سری موارد بیشتر باشه
 - بعضی سوالات چندتا جواب دارن و اون مواردی که با دایره آبی مشخص شده جواب اصلی هست
 - حدود 10 درصد از پاسخ ها اشتباه هست برای همین خودتون حتما با هوش مصنوعی چک کنین
 - اگه از سایت های دیگه هم میگیرین حتما جواب هارو چک کنین چون اونا هم حدود 10درصد جواب اشتباه داره
